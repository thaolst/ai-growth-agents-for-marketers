# Growth Marketing Skills

Skills cho AI agent theo chuẩn Agent Skills spec (agentskills.io).
Cài được qua `npx skills add thaolst/ai-growth-agents-for-marketers`.

## Skills có sẵn

| Skill | Mô tả |
|-------|-------|
| [campaign-brief](./campaign-brief/) | Viết campaign brief hoàn chỉnh từ 5 input |
| [ab-test-analyzer](./ab-test-analyzer/) | Phân tích kết quả A/B test, xác định winner |
| [meu-planning](./meu-planning/) | Làm ngược từ MEU target ra campaign plan |
| [campaign-planning](./campaign-planning/) | Lên plan tổng thể theo tháng / quý |

## Cài đặt

```bash
npx skills add thaolst/ai-growth-agents-for-marketers
```

Hoặc cài từng skill:
```bash
npx skills add thaolst/ai-growth-agents-for-marketers --skill campaign-brief
```

# English

Skills for AI agents following the Agent Skills spec (agentskills.io).

## Install

```bash
npx skills add thaolst/ai-growth-agents-for-marketers
```

Or install specific skills:
```bash
npx skills add thaolst/ai-growth-agents-for-marketers --skill campaign-brief ab-test-analyzer
```
