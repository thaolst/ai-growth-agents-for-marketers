# Planning Agent

Lên campaign plan từ đầu là việc tốn thời gian nhất trong tuần — không phải vì khó, mà vì có quá nhiều thứ cần nghĩ song song: target, segment, mechanic, timeline, budget, channel, risk. Bỏ sót một cái là phải làm lại.

Agent này nhận target đầu vào và trả về plan campaign hoàn chỉnh. Không thay thế được judgment của người làm — nhưng có draft tốt để bắt đầu từ đó nhanh hơn nhiều so với tờ giấy trắng.

## Cách mình dùng

Mình không dùng output của agent để gửi thẳng cho stakeholder. Mình dùng nó như bản draft đầu tiên — agent làm phần khung và logic, mình làm phần điều chỉnh theo context nội bộ mà agent không biết.

Quy trình thực tế: 30 phút với agent → có draft → 45 phút review và điều chỉnh → plan đủ tốt để trình bày. Trước đây quy trình này mất cả ngày.

## Khác gì Campaign Brief Agent

Brief agent (folder 02) tập trung vào một campaign cụ thể — mechanic, user journey, checklist.

Planning agent này nhìn ở level cao hơn — khi bạn có một target lớn và cần quyết định nên chạy bao nhiêu campaign, theo thứ tự nào, với budget phân bổ như thế nào.


# English

Building a campaign plan from scratch is the most time-consuming part of the week — not because it's hard, but because there are too many things to think about in parallel: target, segment, mechanic, timeline, budget, channel, risk. Miss one and you have to redo the whole thing.

This agent takes a target as input and returns a complete campaign plan. It doesn't replace human judgment — but having a solid draft to start from is much faster than a blank page.

## How I use it

I don't send the agent's output directly to stakeholders. I use it as a first draft — the agent handles the structure and logic, I handle the adjustments based on internal context the agent doesn't have.

Real workflow: 30 minutes with the agent → have a draft → 45 minutes reviewing and adjusting → plan ready to present. This used to take a full day.

## How it differs from Campaign Brief Agent

The brief agent (folder 02) focuses on one specific campaign — mechanic, user journey, checklist.

This planning agent looks at a higher level — when you have a large target and need to decide how many campaigns to run, in what order, and how to allocate budget across them.
