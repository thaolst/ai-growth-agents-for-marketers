# Prompt — Agent tư vấn chọn loại agent phù hợp

Dùng khi: bạn biết mình muốn tự động hóa một việc gì đó nhưng chưa biết nên build agent kiểu nào.

Copy toàn bộ phần dưới, paste vào Claude, điền vào chỗ []:
Mình là growth marketer. Mình muốn dùng AI agent để tự động hóa công việc sau:

[Mô tả công việc bạn muốn tự động hóa — càng chi tiết càng tốt]

Thông tin thêm:
- Mình làm việc này bao nhiêu lần mỗi tuần: [số lần]
- Mỗi lần mất bao lâu: [thời gian]
- Input mình có: [dữ liệu, file, số liệu gì]
- Output mình cần: [kết quả cụ thể là gì]
- Mình có biết code không: [có / không / cơ bản]

Phân tích và cho mình biết:
1. Loại agent nào phù hợp nhất cho việc này
2. Cách đơn giản nhất để bắt đầu ngay hôm nay, không cần setup phức tạp
3. Nếu muốn tự động hóa hoàn toàn thì cần thêm gì
4. Rủi ro hoặc giới hạn nào mình cần biết trước

Tell me:
