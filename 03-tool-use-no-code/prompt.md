# Prompt — Agent tổng hợp nhiều file campaign

Copy toàn bộ phần dưới, paste vào Claude. Đính kèm file hoặc paste nội dung vào chỗ []:

Đây là [số lượng] tài liệu campaign của mình:

[Paste nội dung hoặc đính kèm file]

Bối cảnh: mình đang chuẩn bị cho [mô tả — ví dụ: campaign tháng tới, review quý, pitch cho stakeholder].

Từ các tài liệu trên, hãy:
1. Tóm tắt điểm chính của từng tài liệu trong 2-3 câu
2. Tìm pattern chung — những thứ xuất hiện lặp lại hoặc nhất quán
3. Chỉ ra những điểm mâu thuẫn hoặc bất thường đáng chú ý
4. Dựa trên bối cảnh mình cung cấp, rút ra 3 insight quan trọng nhất
5. Đề xuất 2-3 hành động cụ thể mình nên làm tiếp theo

Trả lời ngắn gọn, dùng bullet points, không giải thích dài dòng.

# English

Copy everything below, paste into Claude. Attach files or paste content into the [brackets]:

Here are [number] campaign documents:

[Paste content or attach files]

Context: I'm preparing for [describe — e.g. next month's campaign, quarterly review, stakeholder pitch].

From these documents:
1. Summarize the key points of each document in 2-3 sentences
2. Find common patterns — things that appear repeatedly or consistently
3. Point out contradictions or notable anomalies
4. Based on the context I provided, identify the 3 most important insights
5. Suggest 2-3 specific actions I should take next

Keep it concise, use bullet points, no long explanations.
