# Tool Use — Agent đọc file, tìm kiếm, tổng hợp

Phần lớn công việc growth marketing không thiếu thông tin — thiếu thời gian xử lý thông tin. Mình có brief cũ, có báo cáo, có file số liệu, nhưng để tổng hợp tất cả lại thành insight mất cả buổi.

Tool use là khả năng agent **chủ động đọc file bạn đưa vào, tìm kiếm thêm thông tin, rồi tổng hợp lại** — thay vì chỉ trả lời dựa trên những gì bạn gõ.

Không cần code. Chỉ cần biết cách đưa đúng thứ cho agent.

## Những gì mình thường đưa cho agent

**File để đọc:**
- Brief campaign cũ (PDF, Word, paste text)
- Báo cáo kết quả tháng trước
- Danh sách segment user
- Competitor research

**Câu hỏi để agent xử lý:**
- "Trong 5 campaign này, mechanic nào có conversion rate cao nhất và tại sao?"
- "So sánh campaign tháng 3 và tháng 6, điểm khác biệt chính là gì?"
- "Từ báo cáo này, đề xuất 3 thứ cần thay đổi cho campaign tháng tới"

## Kết quả thực tế

Mình từng mất gần 2 tiếng để đọc lại 8 campaign briefs cũ trước khi lên plan quý mới. Bây giờ mình upload hết lên, hỏi agent một câu, có tổng hợp trong 3 phút. Thời gian đó dành để suy nghĩ về strategy thay vì đọc lại tài liệu.

## Giới hạn thực tế

Agent đọc được những gì bạn cung cấp — không tự truy cập hệ thống nội bộ của công ty. Nếu data nằm trong dashboard cần đăng nhập, bạn vẫn phải export ra rồi paste vào. Phần tự động hóa bước này cần Python — ở phần sau.

*English summary*

Most growth marketing work doesn't lack information — it lacks time to process it. Tool use lets an agent actively read files you provide, search for more context, and synthesize everything — instead of only working from what you type.

No code needed. Just know what to give the agent.

**What I usually provide:**
Past campaign briefs, monthly result reports, user segment lists, competitor research.

**Questions I ask:**
"Of these 5 campaigns, which mechanic had the highest conversion rate and why?" or "Compare March vs June campaign — what's the main difference?"

**Real result:** What used to take 2 hours to read through 8 old briefs now takes 3 minutes.
