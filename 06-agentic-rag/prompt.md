# Prompt — RAG không cần code

Setup một lần: Vào Claude.ai → tạo Project mới tên "Campaign History" → upload tất cả campaign briefs, báo cáo kết quả, và file data vào project này.

Sau đó paste prompt này vào project bất kỳ lúc nào cần:

Từ tất cả tài liệu trong project này, trả lời câu hỏi sau:

[Câu hỏi của bạn]

Khi trả lời:
- Dẫn nguồn cụ thể — file nào, campaign nào
- Nếu có nhiều ví dụ liên quan, liệt kê tất cả
- Nếu không tìm thấy thông tin liên quan, nói rõ thay vì đoán

Ví dụ câu hỏi:
- "Campaign nào có conversion rate cao nhất với new user? Mechanic là gì?"
- "Chúng ta đã thử cashback với dormant user chưa? Kết quả thế nào?"
- "Tháng nào trong năm ngoái campaign performance tốt nhất? Tại sao?"
- "Segment nào chưa bao giờ được nhắm đến trong các campaign cũ?"

# English

One-time setup: Go to Claude.ai → create a new Project named "Campaign History" → upload all campaign briefs, result reports, and data files into the project.

Then paste this prompt into the project whenever you need it:

From all the documents in this project, answer the following question:

[Your question]

When answering:
- Cite specific sources — which file, which campaign
- If multiple relevant examples exist, list all of them
- If no relevant information is found in the documents, say so rather than guessing

Example questions:
- "Which campaign had the highest conversion rate with new users? What was the mechanic?"
- "Have we tried cashback with dormant users before? What were the results?"
- "Which month last year had the best campaign performance? Why?"
- "Which segments have never been targeted in past campaigns?"
