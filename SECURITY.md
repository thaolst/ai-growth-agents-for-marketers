# Security Policy / Chính sách bảo mật

## Supported Versions / Phiên bản được hỗ trợ

This repo is a single-main branch project. All latest commits on `main` receive security updates.

## Reporting a Vulnerability / Báo cáo lỗ hổng

Repo này chứa prompt và code AI agent — không phải production service nên rủi ro bảo mật thấp.
Tuy nhiên, nếu bạn phát hiện:

- API key hoặc secret bị leak trong repo
- Prompt injection có thể gây hại
- Cấu hình không an toàn trong agent code

Vui lòng mở Issue với label `security` hoặc email: tienthaotara@gmail.com

Mình sẽ phản hồi trong vòng 48h.

---

This repo contains AI agent prompts and code — not a production service, so security risk is low.
However, if you find:

- Leaked API keys or secrets
- Harmful prompt injection vectors
- Unsafe configurations in agent code

Please open an Issue with the `security` label or email: tienthaotara@gmail.com

I will respond within 48 hours.
