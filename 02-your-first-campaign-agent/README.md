# Campaign Brief Agent

Viết campaign brief mất 2-3 tiếng. Phần lớn thời gian đó không phải suy nghĩ chiến lược — là format, điền các section, làm cho nó trông đầy đủ.

Agent này nhận 5 input, trả về brief hoàn chỉnh trong 5 phút. Mình dùng output làm bản draft rồi chỉnh thêm context nội bộ — tổng cộng mất khoảng 20 phút thay vì 3 tiếng.

## 5 input cần có

| Input | Ví dụ |
|---|---|
| Target segment | New user, 18-30 tuổi, chưa dùng tính năng loyalty |
| Mục tiêu campaign | Tăng feature adoption 20% trong 30 ngày |
| Budget | 50 triệu VND |
| Loại mechanic | Voucher / Cashback / Game / Bundle |
| Timeline | 2 tuần |

## Cách dùng

Mở `prompt.md` trong folder này, copy toàn bộ, paste vào Claude, điền 5 input vào chỗ trống.

Xem `example-output.md` để biết output trông như thế nào trước khi thử.


# English

Writing a campaign brief takes 2-3 hours. Most of that time isn't strategic thinking — it's formatting, filling sections, making it look complete.

This agent takes 5 inputs and returns a complete brief in 5 minutes. I use the output as a first draft then adjust for internal context — total time around 20 minutes instead of 3 hours.

## 5 inputs you need

| Input | Example |
|-------|---------|
| Target segment | New users aged 18-30, never used loyalty feature |
| Campaign objective | Increase feature adoption 20% in 30 days |
| Budget | 50M VND |
| Mechanic type | Voucher / Cashback / Game / Bundle |
| Timeline | 2 weeks |

## How to use

Open `prompt.md` in this folder, copy everything, paste into Claude, fill in the 5 inputs.

See `example-output.md` to know what the output looks like before trying it.
