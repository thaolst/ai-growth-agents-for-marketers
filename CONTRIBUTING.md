# Contributing

Mình xây repo này từ công việc thực tế, không phải từ lý thuyết. Nếu bạn cũng đang dùng AI agent trong growth marketing và có thứ gì đó work — mình muốn nghe.

## 💬 Bắt đầu từ Discussions

Trước khi gửi issue hay PR, hãy ghé qua **Discussions**:

- **💡 Ideas & Suggestions** — có ý tưởng agent mới? Đăng lên đây trước
- **🙏 Q&A** — cần giúp dùng agent? Hỏi ở đây
- **📢 Share & Showcase** — đã dùng agent cho campaign thật? Kể câu chuyện của bạn
- **🗣️ General** — mọi thứ khác

👉 [Tham gia Discussions](https://github.com/thaolst/ai-growth-agents-for-marketers/discussions)

## Cách contribute

**Thêm prompt hoặc cải thiện prompt có sẵn**

Nếu bạn có prompt tốt hơn cho bất kỳ agent nào, mở Pull Request với file `prompt.md` đã chỉnh sửa. Giải thích ngắn gọn tại sao version của bạn tốt hơn và bạn đã test nó trong tình huống nào.

**Thêm example output**

Nếu bạn đã dùng agent này cho campaign thực tế và muốn share kết quả, thêm vào `example-output.md`. Ẩn danh số liệu trước khi share.

**Báo lỗi hoặc prompt không work**

Mở Issue, mô tả bạn đã dùng prompt như thế nào, input là gì, output bạn nhận được, và output bạn mong đợi.

**Thêm agent mới**

Tạo folder mới theo format `XX-tên-agent/` với đủ 3 file: `README.md`, `prompt.md`, `example-output.md`. Agent phải giải quyết một use case growth marketing cụ thể mà bạn đã test thực tế.

## Format

Giữ nguyên tone của repo — chia sẻ kinh nghiệm thực tế, không viết như tutorial. Nếu chưa test trong công việc thực, chưa cần share vội.

Không dùng dấu gạch ngang dài trong markdown.

# English

This repo is built from real work, not theory. If you're also using AI agents in growth marketing and have something that works — I'd love to hear about it.

## How to contribute

**Add or improve a prompt**

If you have a better prompt for any agent, open a Pull Request with the updated `prompt.md`. Briefly explain why your version is better and what situation you tested it in.

**Add an example output**

If you've used an agent for a real campaign and want to share the result, add it to `example-output.md`. Anonymize any numbers before sharing.

**Report a bug or a prompt that doesn't work**

Open an Issue. Describe how you used the prompt, what the input was, what output you got, and what output you expected.

**Add a new agent**

Create a new folder following the format `XX-agent-name/` with all 3 files: `README.md`, `prompt.md`, `example-output.md`. The agent must solve a specific growth marketing use case you've actually tested.

## Format

Keep the repo's tone — sharing real experience, not writing tutorials. If you haven't tested it in real work yet, it can wait.

No long horizontal rules in markdown.
